# Vanilla command feedback reference:
#   capture.py --commands tools/bds-sweep/command-script.txt --command-wait 600
# One command per line, run in order by an operator (BDSExtractor) on a fresh
# seed-12345 world. `# segment: NAME` starts a segment; commit_fixtures.py
# --commands records each command's segment, and unastar's evidence tests
# replay one segment at a time from the prelude's state. Every segment leaves
# the world as it found it (the player on the platform at 8 200 8, survival,
# full health, empty inventory, no effects, clear weather, time 1000).
# Entity selectors use r=16 so animals of the surrounding chunks never match.
# `!console COMMAND` lines are typed on the server console (owner-level
# commands; capture.py records what BDS prints), `!join NAME` / `!leave NAME`
# bring a second player in and out (its packets are recorded too).
