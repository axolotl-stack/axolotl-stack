# go-raknet parity specification

Behavioural reference for `TransmissionPolicy::Vanilla` (default for
`RaknetStream::connect*`) and the documented differences of
`TransmissionPolicy::Optimized` (default for `RaknetListener`).

### Status vocabulary

| Status | Meaning |
|---|---|
| `match` | Both policies already behaved like go-raknet. |
| `vanilla` | go-raknet behaviour is reproduced by `Vanilla`; `Optimized` intentionally keeps the listed tokio behaviour. |
| `bug` | Plain defect in both policies; fixed in both with a regression test. |
| `shared` | Both policies intentionally deviate (safety bound or strictly-more-correct receive semantics); recorded here, not changed. |
