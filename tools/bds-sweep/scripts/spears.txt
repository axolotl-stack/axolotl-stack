# `UseAsAttack`), missed swings, holding a spear, and a sword's melee reach.
# For packet captures of the same scripted player against BDS and unastar:
# `bds-sweep-client --script tools/bds-sweep/scripts/spears.txt --capture-dir DIR`
# (the player must be an operator). Ticks are the client's input ticks; the
# replay test (`crates/unastar/src/entity/mob/combat/hit/spear_tests.rs`)
# sets up each numbered scenario the way the commands here do.
#

# as adults with a name tag, held still by Slowness 255, and removed between
# scenarios. The hotbar holds an iron spear (0), a diamond spear (1) and an
# iron sword (2); slot 3 is empty.
