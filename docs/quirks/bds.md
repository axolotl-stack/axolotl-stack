# BDS quirks we copy on purpose

unastar copies BDS 1.26.51 exactly, including behaviour that looks permissive, odd or
buggy ([decision 0013](../decisions/0013-copy-bds-behaviour-exactly.md), formerly D3).
Every such behaviour is listed here so it can be revisited one at a time.
