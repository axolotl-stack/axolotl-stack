# Mob runtime constants and their provenance

Built-in mob behaviour that pack data does not carry, with where each value came from. This
table grew under [decision 0023](../decisions/0023-land-parked-branches-with-recorded-deviations.md)
(formerly "the D12 table" in the 2026-10-24 decisions document, removed 2026-11-04). It is a
living reference: replace a **Provisional** row with a measurement when one lands, and re-check
rows confirmed on the 26.30 game build against 1.26.51 when possible.

## Known deviations

approved. Each row names the slice that removes it.
